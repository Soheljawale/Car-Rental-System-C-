Car Rental Management System
Project Overview

The Car Rental Management System is a console-based application developed in C++ to automate the process of managing car rentals. It enables users to add, search, rent, return, and delete car records while maintaining vehicle availability. The project demonstrates the practical implementation of Object-Oriented Programming (OOP), STL, and File Handling.

Problem Statement

Traditional car rental systems often rely on manual record-keeping, making it difficult to track vehicle availability, rental status, and rental records efficiently. This project provides a simple digital solution to automate these operations.

Features
Add new car details
Display all available cars
Search car by ID
Rent a car
Return a rented car
Delete car records
Calculate rental charges
Store records using file handling
